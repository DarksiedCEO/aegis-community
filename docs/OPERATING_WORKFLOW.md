# AEGIS skill-layer operating workflow

1. **Pin the subject.** Repository Integrity Guardian records exact local and
   remote identity and stops on ambiguity.
2. **Compile approved intent.** Blueprint Compiler produces requirement IDs,
   owners, evidence requirements, prohibitions, and stop conditions.
3. **Coordinate work.** Project Manager sequences bounded packages without
   implementing or certifying them.
4. **Implement.** An assigned implementation identity performs only approved
   work and reports `implemented_not_verified`.
5. **Validate authenticity.** Test Authenticity Guardian confirms relevant tests
   ran on the exact candidate without suppression or empty discovery.
6. **Label evidence.** Evidence and Truth Guardian assigns E0–E5 and a permitted
   truth label without signing.
7. **Check completion.** Completion Controller evaluates every requirement while
   preserving gaps and blockers.
8. **Check drift.** Drift Sentinel compares outputs and portable instructions
   with approved sources.
9. **Assess independently.** AEGIS may issue a bounded verdict only when it did
   not implement the candidate and the subject and evidence are sufficient.
10. **Human decision.** Andre retains merge, release, destructive-action,
    external-write, scope, and final approval.

Completion status and certification verdict are different contracts. A completed
local validation run is not remote CI, release approval, or certification.
